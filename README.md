# claudia-pet

<img src="icon/AppIcon.png" width="144" alt="claudia 抱着 Clawd 的图标">

claudia-pet 是一个 Windows 上的 Claude 桌宠。桌宠的名字叫 claudia，她待在 Claude 桌面端的窗口里，跟着 Claude Code 的工作状态做动作，陪你聊天、写代码。

本项目基于 [CrossPet](https://github.com/lokicorvus/crosspet)（lokicorvus）修改而来，并参考了 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet)（PC2005-cloud）。代码、立绘、图标各自的来源和授权写在本文末尾的「来源与授权」和 [NOTICE.md](NOTICE.md) 里。这是非官方同人项目，与 Anthropic 无关。

## 她会做什么

- **跟着 Claude 窗口**：始终在 Claude 窗口上方一层，不置顶，别的窗口能盖住她；Claude 最小化时她跟着藏起来，Claude 关掉后她也退出，下次打开 Claude 再出来。
- **跟着 Claude Code 干活**：你发消息、她思考、读文件、写代码、跑命令、上网查、派子任务、压缩上下文、等你回答、完成、出错，各有一套动作和台词。好几个 Code 会话同时干活时，她身边会出现每个会话的小卡片。
- **显示额度**：名牌下面显示 Claude 的 5 小时 / 每周剩余额度，可选文字或额度条。
- **可以拖、可以扔**：按住拖动时带弹性地跟着鼠标，快速松手能把她扔出去，碰到窗口边会反弹、落地会滑一段。
- **会被摸、会生气**：单击摸头；按住来回晃她会头晕、不耐烦，晃久了会红温赌气，要摸头哄回来。
- **闲着也有事做**：随机哼歌、伸懒腰、打哈欠、抱 Clawd，闲久了会睡着；每个时段第一次见面打招呼，节日换节日装扮。
- **任务通知**：一轮工作完成或出错、需要你授权或回答时，可以弹 Windows 通知。

## 怎么操作她

| 操作 | 效果 |
|---|---|
| 左键单击 | 摸摸头。先轻轻 Q 弹一下，再演「被摸头」；生气时单击就是在哄她（见下文「情绪」）；睡着时单击会把她叫醒 |
| 按住左键拖动 | 带弹性地跟着鼠标走，只能在 Claude 窗口里活动；拖到窗口外松手会被推回来 |
| 拖动中快速松手 | 把她扔出去：按松手时的速度飞，受重力下落，碰到窗口边反弹，落地后横向滑行减速 |
| 拖动中轻轻松手 | 停在当前位置 |
| 按住来回快速晃 | 积攒「红温值」，停稳约 1 秒后才做反应（见下文「情绪」） |
| 右键 | 打开菜单：摸摸头、戳一下、动作、设置…、回到默认位置、暂时隐藏、退出 claudia-pet |
| 右键 →「动作」 | 按分组（日常 / 工作 / 心情 / 互动 / 问候 / 节日）列出全部动作，点一个就演 6 秒，然后回到待机 |
| 托盘图标右键 | 和桌宠右键是同一个菜单 |
| 双击托盘图标 | 她回到默认位置；被「暂时隐藏」时一起显示出来 |
| 快捷键 `Ctrl+Alt+P`（可改） | 暂时隐藏 / 再按一次显示。可在设置里换成 `Ctrl+Alt+H` 或关闭；快捷键被别的程序占用时注册会失败，设置页会提示 |

她的位置按「离 Claude 窗口右下角多远」记住：Claude 窗口挪动或改大小，她跟着走；下次打开还在原来的地方。

右键「退出」时她会挥手道别再走。之后在同一次 Claude 运行期间不会再被自动叫出来，关掉重开 Claude、重启电脑或自己打开程序后恢复。

## 动作一览和触发方式

### 跟着 Claude Code 干活

这些动作需要接入「Claude Code 插件」，并且只在 Claude Code 会话里出现；只在 Claude 桌面端聊天时没有工作状态。

| 动作 | 什么时候出现 |
|---|---|
| 听你说 | 你发出一条消息时，片刻后转为「思考」 |
| 思考 | 两次工具调用之间、等模型回复时 |
| 看书 | Claude 读文件、搜文件、列目录（名字里含 read、grep、glob、list、view、cat 的工具） |
| 写东西 | Claude 写入或修改文件（含 write、edit、patch、replace、create 的工具） |
| 查资料 | Claude 上网（含 web、fetch、browse、search、http 的工具） |
| 派活 | Claude 派子任务（含 agent、task、subagent、delegate 的工具） |
| 敲命令 | 运行命令，以及不属于上面几类的其他工具 |
| 有事问你 | Claude 提问让你选择、请求授权，或 MCP 要你填写内容 |
| 整理记忆 | 压缩上下文（手动 `/compact` 或自动压缩） |
| 开心 | 一轮工作顺利完成 |
| 得意 | 一轮里用了 8 次及以上工具后完成，带胜利特效 |
| 哎呀 | 某个工具出错或被拒绝，或一轮以出错结束 |
| 吃惊 | 你中途打断了这一轮 |
| 道歉 | 出错或被打断后 3 分钟内你又发了消息（多半是在纠正她），她会先说一句「You're absolutely right!」 |
| 忙碌（左 / 右） | 同时有 2 个会话在干活或等你回答：左右来回看，身边每个会话一张小卡片（最多 4 张，多的显示 +N） |
| 忙不过来（左 / 右） | 同时有 3 个及以上会话在干活 |
| 累了 | 额度用掉 90% 以上、她又闲着的时候 |

如果干活的动作持续 3 分钟没有任何新消息（比如 Claude 被中途打断却没发「结束」），她会自己回到待机。「有事问你」不受这个限制，会一直等你。

### 日常

| 动作 | 什么时候出现 |
|---|---|
| 待机 | 平时的样子，有多张图轮换，偶尔眨眼 |
| 哼歌、伸懒腰、抱 Clawd | 闲着时随机出现。间隔按「活跃程度」：安静约 90 秒、标准约 45 秒、活泼约 20 秒，每次上下浮动 20% |
| 打哈欠 | 同上，但要你已经 3 分钟没理她才会出现 |
| 睡觉 | 随机小动作开着（且至少勾了一种动作）时，10 分钟没有任何动静（你没点她、Claude 也没在干活），她会睡着；单击她会打着哈欠醒来 |

随机小动作不会打断干活、拖动、点击或右键点播的动作，可以在设置里整体关闭，或只保留其中几种。

### 问候和节日

| 动作 | 什么时候出现 |
|---|---|
| 时段问候 | 每个时段第一次见到你时演一次：深夜 23–2 点、凌晨 2–5 点、早上 5–11 点、中午 11–14 点、下午 14–18 点、晚上 18–23 点。一直开着时进入新时段，只要她闲着、没睡着，也会打招呼 |
| 节日装扮 | 节日当天第一次见面时演，优先于时段问候：元旦（1 月 1 日）、春节（正月初一到初七）、元宵、端午、中秋、国庆（10 月 1–7 日）、万圣节（10 月 31 日）、圣诞（12 月 24–25 日） |

农历节日的日期内置到 2036 年。正在干活时不打断，只说一句问候。打过的招呼记在本机，重启不会重复。

### 互动和情绪

| 动作 | 什么时候出现 |
|---|---|
| 被摸头 | 左键单击，或右键「摸摸头」 |
| 吃惊 | 右键「戳一下」 |
| 晕乎乎 | 晃她但还没到生气的程度，停下后 |
| 不耐烦 → 鼓脸 → 红温 | 晃得越久红温值越高：到 20 不耐烦，到 45 鼓脸，到 75 红温（冒蒸汽、发抖） |
| 赌气 | 红温约 3.5 秒后背过身去；45 秒没人哄会自己慢慢消气 |
| 被哄 | 生气或赌气时单击摸头 |
| 原谅你了 | 赌气时连摸 3 下；没到赌气时每摸一下红温值降 25，降到 20 以下就原谅你 |
| 再见 | 右键「退出」时 |

红温值不管它也会每秒降 2（赌气时不降，要哄）。在下面几种情况下，晃她不会马上生气：

- **Claude 正在干活**：她只抱怨一句「别晃啦，我在干活呢」，然后接着干；等这一轮干完，再按积攒的火气发作，换一套「干活时被晃」的台词。
- **在等你回答**：她不会换掉提问的样子，只催你快回答。
- **好几个会话同时在忙**：身边的小卡片会被晃得东倒西歪。

## 设置

右键 →「设置…」打开。

| 页面 | 可以改什么 |
|---|---|
| 外观 | **人物大小**（60%–160%，可还原）；**文字大小**（60%–160%，名牌、气泡、额度的字；锁住时跟着人物大小一起变）；**显示名字**开关；**自定义名字**（最多 20 个字符，保存后立即显示，留空或点「还原」恢复 `claudia`）；**背景光晕**（自动 / 始终显示 / 关闭，自动时深色模式下不显示） |
| 额度 | 显示样式：文字，或每个额度一条的额度条（剩得越少颜色越暖） |
| 接入 Claude | Claude Code 插件、Claude 桌面端（MCP）两项的接入和撤销，并显示插件上次发来消息的时间 |
| 互动 | **点击 Q 弹**开关；**拖拽与抛掷**开关（关闭后直接跟手、不会被扔出去）；**力度**（越大跟得越紧、扔得越快）；**重力**（0 为无重力）；**反弹系数**；**地面摩擦**；**弹性幅度**（人物的挤压变形，0 为关闭）；**顶部反弹**开关；一键恢复默认手感 |
| 日常 | **随机小动作**开关；**活跃程度**（安静 / 标准 / 活泼）；**允许的动作**（哼歌、伸懒腰、打哈欠、抱 Clawd，可多选） |
| 通用 | **任务通知**：完成或出错、等待授权或回答、仅在 Claude 不在前台时通知，三项默认都打开；**隐藏快捷键**；**省电模式**（身边特效刷新慢一点、闲着时更快停下，人物动作照旧）；打开**角色**文件夹和**数据和日志**文件夹 |
| 关于 | 版本、项目来源、素材授权和商标说明 |

Windows 的勿扰模式和通知设置会影响任务通知能不能弹出来。

## 安装

目标平台为 Windows 10/11，目前只在 Windows 11 上实际验证过。运行需要 .NET Framework 4.8（Windows 自带）和 Microsoft Edge WebView2 运行时（Windows 11 自带）。

构建只需要 PowerShell 7，不用装 .NET SDK 或 Visual Studio。第一次构建会从 nuget.org 下载 WebView2 SDK。在项目根目录执行：

```powershell
pwsh -NoProfile -File scripts/build.ps1
pwsh -NoProfile -File scripts/install.ps1
```

程序装在 `%LOCALAPPDATA%\Programs\claudia-pet`，设置、日志和状态文件在 `%USERPROFILE%\.claudia`，不需要管理员权限，也不会加开机自启。

## 接入 Claude

右键她 →「设置…」→「接入 Claude」，把两项都点「接入」：

1. **Claude Code 插件**：新开一个 Code 会话后生效。负责工作状态、额度和通知，会话开始时也会把她叫出来。
2. **Claude 桌面端（MCP）**：完全退出 Claude 再打开后生效。Claude 一打开就把她叫出来，只聊天、不开 Code 会话时她也在。这个 MCP 不提供任何工具，只用来跟着 Claude 一起启动。

接入前会先备份要改的配置：插件改 `~/.claude/settings.json`，桌面端改 `claude_desktop_config.json`，备份名为 `原文件名.bak-claudia-时间`，只保留最近 3 份。也可以运行安装目录里的 `claudia-pet.exe --connect all` 一次接入两项。

## 卸载

```powershell
pwsh -NoProfile -File scripts/uninstall.ps1
```

卸载会撤销两项接入，删除程序和数据；加 `-KeepData` 可以保留设置和数据。

## 本机数据

Claude Code 插件只往本机的 `%USERPROFILE%\.claudia\state` 写几个小文件：当前动作、用到的工具名、会话编号、额度百分比和通知事件。不写对话内容、代码或文件路径。claudia-pet 不联网，不向任何模型 API 发请求，动作和台词都是预设的。

## 已知限制

- 只做 Windows，只认 Claude 桌面端。
- 目前只在 Windows 11、单显示器、100% 缩放下完整用过；多显示器、其他缩放比例和 Windows 10 还没有完整验证。
- 真实 Code 会话里的 Windows 通知还没有完整验收。
