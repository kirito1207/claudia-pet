## 五、要补帧才能和动画连贯的静态姿态

现在静态立绘只有一张（站不稳有两张），靠 CSS 晃动撑着；夹在动画中间时会显得“定住了”。没有视频工具时，可以像站不稳那样每个姿态多画 2–4 张关键帧轮流切换。按优先级：

| 优先级 | 姿态 | 为什么 | 建议补几张 |
|---|---|---|---|
| 高 | bonk 撞头、stagger 站不稳、fallen 摔倒、faceplant 趴地、getup 爬起 | 一段接一段演（站不稳 → 趴地 → 爬起），前后都是动画（待机），单张图最显僵 | 每个 2–3 张：撞头（撞上 / 捂头 / 揉头），摔倒和趴地（着地 / 挣扎），爬起（撑地 / 半起 / 拍裙子） |
| 高 | annoyed（动画）→ puffed → redhot → sulk | 生气一档档往上走，第一档已是动画，后三档是单张，升级时从会动变成不动 | redhot 2–3 张（跺脚、冒气），puffed 和 sulk 在第一节重画时各画 2 张 |
| 中 | asking 有事问你、listening 听你说、reading 看书、tired 累了、delegating 派活 | 一停就是几十秒到几分钟，前后是动画（思考、待机） | 各 2–3 张做小循环（翻页、眨眼、点头）；listening、reading、tired 在第一节重画时一起画 |
| 中 | busy / swamped 左右 | 多会话时每 1.5 秒左右切换，已经有左右两张，能动起来 | 暂不需要；busy 在第一节重画 |
| 低 | proud、sorry、update、coaxed、forgiven、oops、dizzy、六个问候、元旦 | 几秒的一次性反应，单张加 CSS 晃动够用 | 不补；其中要重画的按第一节 |
