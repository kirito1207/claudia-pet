# Claudia 性能优化与审查修复报告

2026-11-07（日本时间）。改动基于审查分支 `claude/kind-blackburn-304e7f` 的 `f35f8a6fdee0dda416e59af017a720f3802f7a0e`，包含上一轮报告中六项已确认的问题。源码改动保存在该工作树，验证使用独立的构建和数据目录。

## 性能

- **启动时跳过重复拷贝。** 程序对照内置角色目录的文件名、大小和修改时间。素材一致时只检查文件信息。确需更新时先完整复制，再切换目录。若复制失败，仍可使用上次的完整角色。隔离测试用真实素材，首次同步 80 张动画图及其他角色文件耗时 182.5 毫秒，素材一致时连续 7 次同步检查的中位数为 19.0 毫秒。这两组数测的是同步步骤，分别对应首次复制和素材已同步的场景。
- **切换动作时取消过期图片任务。** 新动作替换旧动作时，程序会中止尚可中止的读取、清掉旧任务的超时回退，并释放后来才完成的过期位图。当前动作解码超时时，如果文件已读完，回退直接用这份数据。Edge 用真实精灵图验证了正常解码、超时回退和取消三条路径，每条只向素材地址发出一次请求。已经开始的位图解码仍可能跑到完成，桌面版连续操作的帧间隔和内存峰值尚未复测。

## 审查修复

| 问题 | 处理结果 |
| --- | --- |
| 打包可递归删掉误指定的目录 | `-Out` 限定为当前工作树中 `build` 或 `dist` 的直接子目录，SDK 缓存除外。已有输出需要脚本生成的标记。新版先在临时目录完成打包，再替换旧包。误填仓库根目录、整个 `build`、SDK 缓存或无标记的旧目录都会被拒绝。已在复制素材失败时验证旧包仍可用。 |
| 启动反复重拷，复制失败可能留下残缺的素材 | 已改成先检查、确需更新时完整复制再替换。测试覆盖首次同步、跳过重复同步、更新和移除素材、复制失败，以及中断后的恢复。 |
| 快速切动作时旧图片继续加载，超时可能重复读图 | 取消过期请求和回退，超时优先复用已有数据，并释放过期位图。 |
| 额度文件写入失败后，插件没有继续交还控制 | 写入失败时仍会调用 Claude 的下一步。已用写入异常验证。 |
| 撤销接入失败，卸载脚本仍报成功并删文件 | 命令行接入或撤销失败时返回非零退出码。卸载脚本收到失败后会在删除程序和数据之前停止。安装脚本也会报出接入失败。已用独立 Claude Code 配置验证有效配置的接入和撤销，以及坏配置返回失败并保留原文件。 |
| 多会话卡片显示过时动作 | 先取消前一个排队动作，再判断最新动作是否已显示。已用 `reading → thinking → reading` 验证。 |

旧版脚本生成的 `dist\claudia-pet`、`build\native-tests` 没有新标记；目录里有 `claudia-pet.exe` 和 `web\index.html` 时也认作构建产物，可以直接在原处重建（2026-11-07 Claude 调宽）。其他没有标记的目录仍会被拒绝。

带 `-Connect` 的安装需要新版程序配套，旧程序的退出码无法区分接入成功和失败，脚本会要求先重新打包。卸载脚本遇到旧版安装时照常撤销接入并卸载，只提示一句无法确认撤销结果、请自己核对两份 Claude 配置（2026-11-07 Claude 调宽，原先会直接拒绝卸载）。

## 验证与范围

七项现有 JavaScript 测试、原生 WPF 拖拽与通知策略测试、正常打包和同目录重建均通过。额外验证了危险输出路径检查、打包失败保留旧包、素材同步恢复、HTTPS 精灵图加载和错误退出码。隔离卸载测试确认，遇到旧程序或接入撤销返回失败时，脚本保留了安装文件。正式安装版、Claude 桌面端 MCP 配置和用户实际拖动时的性能留待实机验收。

审查中的 GPU 内存占用归因、Claude 宿主是否跨会话复用同一个插件注册闭包仍待确认。本次没有把这两条推测当作已确认的故障。

本机已并行启动标有「测试版」的独立副本。它使用单独的实例锁、设置、状态文件和 WebView2 数据。已核对两份程序的进程、可见窗口和测试版浏览器数据目录。测试副本关闭了通知，初始快捷键设为关闭，接入 Claude 的操作也在该副本中禁用。

## 后续优化

参考 dsh-pet 0.3.7 的窗口位置去重和点击区域更新方式。Claudia 按物理像素跳过重复移窗，保留原有拖动计算及事件。点击区域改为网页在布局变化时主动上报，变形动画期间仍按原间隔采样。精灵图画布只在动作切换、人物框大小或像素比例变化时重新排版。

原生 WPF 测试验证了重复移窗去重、松手时丢弃过期帧，以及点击区域随窗口缩放。Edge 自动测试检查了点击区域更新、精灵图对齐和尺寸变化。构建输出放在审查工作树的独立目录。本轮没有安装程序或测量日常使用中的 CPU 占用和帧时间。

精灵图调度随后改为按需启动。窗口隐藏时停止精灵图和光晕计时，恢复时从当前帧继续。一次性动画到达尾帧后保留画面，光晕可见时接手更新。播放中的帧率仍为 12 FPS。静态立绘和补帧序列沿用各自的播放路径。Edge 上的精灵图、情绪与翻页测试均通过，新增检查覆盖了隐藏时加载、从当前帧恢复、尾帧停表和光晕接手。
