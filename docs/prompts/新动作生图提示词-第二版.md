# claudia 新动作立绘 · 生图提示词（第二版）

一共 5 张：撞头、摔倒、趴地、爬起已经按第 1～4 节画好（第二轮，大小不一致的问题由对齐脚本缩放解决）；**现在只差新增的摇晃站不稳（第 5 节）**。每个动作下面有：

- **要附的 3 张图**：已经按上传顺序放在本文件旁边的 `refs/<动作>/` 文件夹里，文件名前的数字就是第几张，整组拖进 Codex 即可。
- **一整段完整提示词**：直接全部复制给 Codex，不用再自己拼。

写法沿用 CrossPet v1.3.8 的「角色生图提示词」（CC BY-NC-SA 4.0）。「通用格式规则」的大部分取自 CrossPet 原文；「角色锁定」取自 CrossPet 原文，但删去了最后两句（「每张都拿着书」「情绪通过书表达」），因为它们和书掉在地上的动作冲突。附图说明、手的画法、宽度限制、姿态描述是本项目新写的。

## 这几张图在程序里怎么接（画的时候心里有数）

| 她被扔出去后碰到 | 依次播放 | 书在哪 |
|---|---|---|
| 顶边或左右边 | 撞头 | 掉在脚边 |
| 底边（4 成） | 摇晃站不稳 → 趴地 → 爬起 | 还拿在手里 → 飞到手前面 → 抱回怀里 |
| 底边（6 成） | 摔倒（坐地）→ 爬起 | 在身前地上 → 抱回怀里 |

身体动作播完，如果之前被晃得有火气，再接不耐烦、鼓脸、红温这些情绪动作。摇晃时的左右摆动由程序做，图只需要一张站着的「站不稳」。

## 画之前

1. **打开透明背景**：生图工具里设置 `transparent_background: true`。第一版撞头图出现白底和地面投影，就是这个没生效。
2. **一次只画一张**，画完对照文末的「自查清单」看一遍再画下一张。建议顺序：撞头（只改手，最容易）→ 摇晃 → 摔倒 → 爬起 → 趴地（最难）。
3. **存原图**：把 Codex 生成的原始文件（一般是 PNG）存到本文件夹，文件名分别是 `bonk.png`、`stagger.png`、`fallen.png`、`faceplant.png`、`getup.png`。之后由对齐脚本统一缩放、底边对齐、转成 WebP。

## 上一轮出现的问题（这一版都写进了提示词）

**撞头第一版（不能用）**

| 问题 | 原因 | 这一版的处理 |
|---|---|---|
| 双手把书举在头顶，不像撞到头 | 姿势示例 `stretch.webp` 本身是举书的姿势，被直接照搬 | 不再附整体姿势相差很大的示例图；提示词写明「双手空着」「不要照抄示例图的姿势」 |
| 表情像生气，和「红温」分不开 | 示例图 `redhot.webp` 是生气表情，加上提示词没强调 | 撞头只附含泪的 `oops.webp`；写明「是疼，不是生气，不要皱眉」 |
| 画了爆炸星、晃动线、强调线 | 原规则只列了少数符号 | 把这些都点名禁止；说明脸上的泪滴可以画，飘在空中的不行 |
| 白底和地面投影 | 透明背景开关没生效 | 见「画之前」第 1 条 |
| 画布是竖长方形 | — | 再次强调正方形 |

**撞头第二版（可用，但这次重画）**

| 小瑕疵 | 这一版的处理 |
|---|---|
| 手画出了手指和手掌纹路，现有立绘都是不画手指的圆手 | 新增「HANDS」规则：圆圆的连指手套状小手，不画单独的手指。4 张都适用 |
| 书放在脚边左侧，让整张图比普通站立图宽一些 | 新增规则：书要放在她身边、不超出头发的宽度。这张的位置其实还在范围内，保持即可 |
| 人物的不透明度只有约 99%（不是百分之百） | 这是压缩造成的，不用在提示词里改，对齐脚本会统一补成完全不透明 |

**预防**：趴地是横着的，太宽会在桌宠窗口里被裁掉。这一版要求趴地时屈膝、靴子翘起，整体留在画布内、左右留边。

## 自查清单（每张画完都对一遍）

- [ ] 背景真透明：没有白底、没有地面投影、没有外框。
- [ ] 画面里没有任何飘着的符号：爆炸星、晃动线、强调线、尘土、汗滴图标、文字都不能有（脸上的泪滴可以）。
- [ ] 手是圆圆的连指手套状，没有单独的手指和手掌纹路。
- [ ] 人物和参考图一样大，没有被放大填满画面；坐着、趴着时，上方留出透明空白。
- [ ] 碰地的部分（脚、屁股、膝盖、手、书）贴着图片底边。
- [ ] 书在她身边，不超出头发的宽度；整体在画布内，左右留边。
- [ ] 发饰在她的左侧（画面右侧），丝带、流苏、耳坠、胸针、靴子都和参考图一致。
- [ ] 表情：撞头和摔倒是「疼」，不是生气；摇晃是「晕、站不稳」，不哭；爬起是害羞的笑。
- [ ] 摇晃那张：双脚踩稳在画面正中间，身体没有已经倒向一边（左右摆动由程序做）。
- [ ] 正方形画布，1024×1024 或更大。
